# HireGuard AI

A polished, responsive front-end dashboard for responsible hiring intelligence. HireGuard AI helps hiring teams monitor candidate activity, review fairness signals, and keep human judgment in the loop.

## Features

- Responsive hiring analytics dashboard
- Candidate activity and shortlist trend visualization
- Fairness score snapshot with accessible status language
- Human review queue and recent activity feed
- Add-candidate modal with lightweight interaction
- No build step or dependencies: open `index.html` directly

## Run locally

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

> This is a front-end prototype. Fairness scores and candidate data are illustrative and should not be used to make real employment decisions without appropriate validation, governance, and human review.
